# План привлечения клиентов для производителя шкафов для санузла

1. **Яндекс.Директ на горячие запросы** («шкаф для ванной на заказ», «пенал в санузел + город») с посадкой на готовый лендинг с конфигуратором — заявки начинают приходить с первой недели, пока работает SEO.
2. **SEO по коммерческим кластерам**: посадочные страницы под каждый тип шкафа (подвесные, встраиваемые, зеркальные с подсветкой) + микроразметка Product из ТЗ — через 2–3 месяца бесплатный трафик людей, которые уже ищут именно этот продукт.
3. **Карточки на Яндекс.Маркете, Авито и ВБ с фото реальных проектов** и ссылкой на замер — охват покупателей, которые выбирают мебель на маркетплейсах, а не в поиске.
4. **Партнёрская программа для дизайнеров и ремонтных бригад** (вознаграждение 5–10% с заказа + приоритетный расчёт) — стабильный канал оптовых заявок с объектов, а не разовые частные заказы.
5. **Геореклама и отзывы**: продвижение в Яндекс.Картах и 2ГИС + сбор видеоотзывов «до/после» из раздела портфолио — клиенты «рядом со мной» видят рейтинг и звонят в обход сайта.
6. **Сквозная аналитика на заявки**: цели в Метрике на все формы и клики по мессенджерам + Вебвизор — видно, какой канал даёт реальные обращения, и бюджет перенаправляется туда, а не «на узнаваемость».
